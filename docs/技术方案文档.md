## 3. 数据库设计

### 3.1 ER 关系图

```
authors (1) ----< books (N)
```

一个作者可对应多本书；一本书通过 `author_id` 外键关联主要作者。

### 3.2 建表 DDL

```sql
CREATE TABLE IF NOT EXISTS authors (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,
    douban_url  TEXT,
    birthplace  TEXT,
    birth_date  TEXT,
    description TEXT,
    continent   TEXT,
    country     TEXT,
    province    TEXT,
    city        TEXT,
    latitude    REAL,
    longitude   REAL,
    created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS books (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    douban_id    TEXT UNIQUE,
    title        TEXT NOT NULL,
    author_name  TEXT,
    translator   TEXT,
    publisher    TEXT,
    publish_date TEXT,
    pages        TEXT,
    price        TEXT,
    isbn        TEXT,
    rating       REAL,
    rating_count INTEGER,
    summary      TEXT,
    book_url     TEXT,
    cover_url    TEXT,
    rank         INTEGER,
    author_id    INTEGER,
    created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (author_id) REFERENCES authors(id)
);

CREATE INDEX IF NOT EXISTS idx_books_douban_id ON books(douban_id);
CREATE INDEX IF NOT EXISTS idx_authors_name ON authors(name);
```

### 3.3 去重策略

- **books**：按 `douban_id` 唯一约束去重，重复运行时 UPDATE 已有记录
- **authors**：按 `name` 查询去重，已存在则合并补充信息

## 4. 模块设计

### 4.1 config.py — 配置中心

负责集中管理所有可调配置项：

```python
DB_PATH            # 数据库文件路径
TOP250_BASE_URL    # https://book.douban.com/top250
REQUEST_DELAY_MIN  # 最小请求间隔：3秒
REQUEST_DELAY_MAX  # 最大请求间隔：5秒
MAX_RETRIES        # 最大重试次数：3
RETRY_BACKOFF      # 退避倍数：2
NOMINATIM_DELAY    # Nominatim 请求间隔：1.1秒
USER_AGENTS        # 12 个主流浏览器 UA 字符串
CONTINENT_MAPPING  # 中文地名 → (大洲, 国家) 映射
COUNTRY_TO_CONTINENT  # Nominatim 英文国家 → 大洲映射
```

### 4.2 db.py — 数据库模块

| 函数 | 说明 |
|------|------|
| `get_connection()` | 返回启用外键约束的 sqlite3 连接 |
| `init_db()` | 创建 books/authors 表及索引（IF NOT EXISTS） |
| `insert_author(data)` | 按 name 去重，存在则 UPDATE，返回 author_id |
| `insert_book(data)` | 按 douban_id 去重，存在则 UPDATE，返回 book_id |
| `update_author_geo(id, lat, lng, continent, country)` | 更新经纬度和大洲/国家 |
| `get_authors_without_geo()` | 查询有 birthplace 但无经纬度的作者 |

### 4.3 playwright_scraper.py — Playwright 浏览器爬虫模块

#### 核心函数

```
run_playwright_scraper()
  └─ 启动 Chromium 浏览器（headless 模式）
  └─ 预热 Cookie（访问豆瓣首页）
  └─ scrape_all_top250(page)      # 抓取 Top250 列表
  └─ for each book:
       scrape_book_detail(page, url)   # 书籍详情页
       scrape_author_page(page, url)   # 作者详情页

scrape_top250_page(page, start)
  └─ page.goto(url)
  └─ page.evaluate() 提取 DOM 数据
  └─ 返回书籍基本信息列表

scrape_book_detail(page, book_url)
  └─ page.goto(book_url)
  └─ 从 #info 提取作者链接（href="/author/ID"）
  └─ 从 #link-report 提取内容简介
  └─ 返回完整书籍信息

scrape_author_page(page, author_book_url)
  └─ page.goto(author_book_url)  # book.douban.com/author/ID
  └─ 自动跳转至 www.douban.com/personage/ID/
  └─ 提取姓名、出生地、出生日期、简介
  └─ 返回作者信息
```

#### 数据抓取流程（MVP验证通过）

1. **列表页** → 提取书籍基本信息 + rank + 作者链接
2. **详情页** → 获取作者超链接 + 完整书籍信息(ISBN/Pages/Summary)
3. **作者页** → 获取作者出生地、出生日期、简介
4. **地理编码** → Nominatim API 获取经纬度/国家/大洲

### 4.4 geocoder.py — 地理编码模块

```
geocode_location(location_text)
  └─ time.sleep(1.1)  # 遵守 Nominatim 频率限制
  └─ geolocator.geocode(text, language="zh", addressdetails=True)
  └─ 失败时简化地名重试（去掉"省/市/县/区"后缀）
  └─ 从 address 详情提取 country、country_code
  └─ 通过 COUNTRY_TO_CONTINENT 映射获取大洲
  └─ 返回 {latitude, longitude, continent, country}
```

大洲推断优先级：
1. Nominatim 返回的 `country` 字段 → 查 `COUNTRY_TO_CONTINENT` 映射
2. 输入文本 → 查 `CONTINENT_MAPPING` 关键字匹配
3. Nominatim 返回的 `country_code` → 查 `continent_by_code` 映射

### 4.5 main.py — 主流程

```
main()
  1. init_db()
  2. create_session()
  3. scrape_top250_list(session)          # 10 页列表
  4. for each book:
       scrape_book_detail(session, url)    # 书籍详情
       insert_author(author_data)          # 作者入库（去重）
       insert_book(book_data)              # 书籍入库
  5. get_authors_without_geo()
     for each author with birthplace:
       geocode_location(birthplace)
       update_author_geo(...)
  6. 输出统计摘要
```

## 5. Playwright MCP 工具使用

本项目使用 Playwright MCP 工具进行浏览器自动化操作，主要工具：

| 工具 | 用途 |
|------|------|
| `browser_navigate` | 导航到指定 URL |
| `browser_snapshot` | 获取页面可访问性快照 |
| `browser_evaluate` | 在页面上下文执行 JavaScript |
| `browser_wait_for` | 等待指定时间或条件 |

### 5.1 页面抓取模板

```javascript
// 抓取书籍详情
const result = await page.evaluate(() => {
  const data = {};
  // 从 #info 提取字段
  const info = document.querySelector('#info');
  if (info) {
    const authorLink = info.querySelector('a[href*="/author/"]');
    if (authorLink) {
      data.author_name = authorLink.textContent.trim();
      data.author_url = authorLink.href;
    }
    // 解析其他字段...
  }
  // 从 #link-report 提取简介
  const intro = document.querySelector('#link-report .intro');
  if (intro) data.summary = intro.textContent.trim();
  return data;
});
```

## 6. 反爬策略

| 策略 | 实现 | 参数 |
|------|------|------|
| 随机延迟 | `asyncio.sleep(random.uniform(min, max))` | 3-5 秒（可配置） |

| Cookie 保持 | 浏览器上下文复用，预热首页获取 Cookie | — |
| 页面跳转等待 | 等待 3 秒等待自动跳转完成 | — |

## 7. 错误处理策略

| 场景 | 处理方式 |
|------|----------|
| 网络超时 / 连接失败 | 重试机制，指数退避 |
| HTTP 403 / 页面不存在 | 跳过该项，记录日志 |
| 地理编码失败 | 简化地名重试，失败则手动补充已知坐标 |
| 数据库写入 | try/except 捕获，记录错误，不崩溃 |
| 作者页面不存在 | 使用已知信息或跳过 |
