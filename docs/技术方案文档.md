## 3. 数据库设计

### 3.1 ER 关系图

```
authors (1) ----< books (N)
```

一个作者可对应多本书；一本书通过 `author_id` 外键关联主要作者。

### 3.2 建表 DDL

```sql
CREATE TABLE IF NOT EXISTS authors (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,
    douban_url  TEXT,
    birthplace  TEXT,
    birth_date  TEXT,
    description TEXT,
    continent   TEXT,
    country     TEXT,
    latitude    REAL,
    longitude   REAL,
    created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS books (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    douban_id    TEXT UNIQUE,
    title        TEXT NOT NULL,
    author_name  TEXT,
    translator   TEXT,
    publisher    TEXT,
    publish_date TEXT,
    pages        TEXT,
    price        TEXT,
    isbn         TEXT,
    rating       REAL,
    rating_count INTEGER,
    summary      TEXT,
    book_url     TEXT,
    cover_url    TEXT,
    rank         INTEGER,
    author_id    INTEGER,
    created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (author_id) REFERENCES authors(id)
);

CREATE INDEX IF NOT EXISTS idx_books_douban_id ON books(douban_id);
CREATE INDEX IF NOT EXISTS idx_authors_name ON authors(name);
```

### 3.3 去重策略

- **books**：按 `douban_id` 唯一约束去重，重复运行时 UPDATE 已有记录
- **authors**：按 `name` 查询去重，已存在则合并补充信息

## 4. 模块设计

### 4.1 config.py — 配置中心

负责集中管理所有可调配置项：

```python
DB_PATH            # 数据库文件路径
TOP250_BASE_URL    # https://book.douban.com/top250
REQUEST_DELAY_MIN  # 最小请求间隔：3秒
REQUEST_DELAY_MAX  # 最大请求间隔：5秒
MAX_RETRIES        # 最大重试次数：3
RETRY_BACKOFF      # 退避倍数：2
NOMINATIM_DELAY    # Nominatim 请求间隔：1.1秒
USER_AGENTS        # 12 个主流浏览器 UA 字符串
CONTINENT_MAPPING  # 中文地名 → (大洲, 国家) 映射
COUNTRY_TO_CONTINENT  # Nominatim 英文国家 → 大洲映射
```

### 4.2 db.py — 数据库模块

| 函数 | 说明 |
|------|------|
| `get_connection()` | 返回启用外键约束的 sqlite3 连接 |
| `init_db()` | 创建 books/authors 表及索引（IF NOT EXISTS） |
| `insert_author(data)` | 按 name 去重，存在则 UPDATE，返回 author_id |
| `insert_book(data)` | 按 douban_id 去重，存在则 UPDATE，返回 book_id |
| `update_author_geo(id, lat, lng, continent, country)` | 更新经纬度和大洲/国家 |
| `get_authors_without_geo()` | 查询有 birthplace 但无经纬度的作者 |

### 4.3 scraper.py — 爬虫模块

#### HTTP 请求封装

```
create_session()
  └─ 创建 requests.Session
  └─ 配置 HTTPAdapter（含 Retry 策略）
  └─ 设置默认 Accept / Accept-Language / Connection headers
  └─ 访问豆瓣首页预热，获取初始 Cookie

fetch_page(session, url, referer)
  └─ random.uniform(3, 5) 秒延迟
  └─ 随机轮换 User-Agent
  └─ 设置 Referer header
  └─ GET 请求，超时 15 秒
  └─ 403 时额外等待 10-20 秒重试一次
  └─ 失败返回 None
```

#### 列表页解析

豆瓣 Top250 列表页结构：
```html
<table width="100%">
  <td width="20px">  <!-- 排名 -->
  <div class="pl2">
    <a href="/subject/{douban_id}/">书名</a>
  </div>
  <p class="pl">作者 / 出版社 / 年份 / 价格</p>
  <span class="rating_nums">评分</span>
  <span class="pl">(N人评价)</span>
</table>
```

`parse_top250_list(html)` 解析逻辑：
1. 查找所有 `<table width="100%">`
2. 提取书名链接、douban_id（从 URL 正则提取）
3. 解析 `<p class="pl">` 中的元信息（`/` 分割，倒序解析价格/日期/出版社/作者）
4. 分页 URL：`?start=0, 25, 50, ..., 225`（共 10 页）

#### 书籍详情页解析

豆瓣书籍详情页关键结构：
```html
<div id="info">
  <span class="pl">作者:</span> <a href="/author/{id}/">作者名</a>
  <span class="pl">出版社:</span> 出版社名
  <span class="pl">出版年:</span> 2023-1
  <span class="pl">页数:</span> 300
  <span class="pl">定价:</span> CNY 59.00
  <span class="pl">ISBN:</span> 9787xxx
</div>
<strong class="rating_num">9.0</strong>
<a class="rating_people"><span>50000</span></a>
<div id="link-report">
  <div class="intro">内容简介...</div>
</div>
```

`parse_book_detail(html)` 提取字段：title, author_name, translator, publisher, publish_date, pages, price, isbn, rating, rating_count, summary, author_douban_url

#### 作者页面解析

豆瓣作者页 `/author/{id}/` 结构：
```html
<ul>
  <li>出生地: 法国巴黎</li>
  <li>出生日期: 1913-11-07</li>
</ul>
<div class="indent">
  <span class="all hidden">作者简介...</span>
</div>
```

同时支持从简介文本中通过正则提取出生地（`出生于XXX`、`生于XXX`、`born in XXX` 等模式）。

### 4.4 geocoder.py — 地理编码模块

```
geocode_location(location_text)
  └─ time.sleep(1.1)  # 遵守 Nominatim 频率限制
  └─ geolocator.geocode(text, language="zh", addressdetails=True)
  └─ 失败时简化地名重试（去掉"省/市/县/区"后缀）
  └─ 从 address 详情提取 country、country_code
  └─ 通过 COUNTRY_TO_CONTINENT 映射获取大洲
  └─ 返回 {latitude, longitude, continent, country}
```

大洲推断优先级：
1. Nominatim 返回的 `country` 字段 → 查 `COUNTRY_TO_CONTINENT` 映射
2. 输入文本 → 查 `CONTINENT_MAPPING` 关键字匹配
3. Nominatim 返回的 `country_code` → 查 `continent_by_code` 映射

### 4.5 main.py — 主流程

```
main()
  1. init_db()
  2. create_session()
  3. scrape_top250_list(session)          # 10 页列表
  4. for each book:
       scrape_book_detail(session, url)    # 书籍详情
       insert_author(author_data)          # 作者入库（去重）
       insert_book(book_data)              # 书籍入库
  5. get_authors_without_geo()
     for each author with birthplace:
       geocode_location(birthplace)
       update_author_geo(...)
  6. 输出统计摘要
```

## 5. 反爬策略

| 策略 | 实现 | 参数 |
|------|------|------|
| 随机延迟 | `time.sleep(random.uniform(min, max))` | 3-5 秒（可配置） |
| UA 轮换 | 每次请求随机选取 12 个 UA 之一 | config.USER_AGENTS |
| Cookie 保持 | requests.Session 复用，预热首页获取 Cookie | — |
| Referer 设置 | 每次请求携带上一页 URL 作为 Referer | — |
| 指数退避重试 | HTTPAdapter(Retry) + 403 特殊处理 | backoff_factor=2, max=3 |
| 403 特殊处理 | 额外等待 10-20 秒后重试一次 | — |

## 6. 错误处理策略

| 场景 | 处理方式 |
|------|----------|
| 网络超时 / 连接失败 | Retry 自动重试（最多 3 次，指数退避） |
| HTTP 403 | 额外等待后重试一次；仍失败则返回 None，跳过该项 |
| HTTP 4xx / 5xx（非403） | 记录 ERROR 日志，返回 None，跳过 |
| HTML 元素缺失 | 返回已解析的部分数据，缺失字段为 None |
| 地理编码失败 | 记录 WARNING，坐标留 NULL，不中断流程 |
| 数据库写入 | try/except 捕获，记录 ERROR，不崩溃 |
| 程序中断 | sqlite3 连接使用 context manager，事务自动提交/回滚 |

## 9. 已知限制

1. **豆瓣反爬**：豆瓣对爬虫有主动防护，部分请求可能返回 403。当前策略可覆盖大部分情况，但在高频运行时可能触发更严格的限制
2. **作者页面覆盖率**：并非所有书籍作者都有豆瓣作者页面，无页面的作者出生地字段将为空
3. **出生地解析准确率**：Nominatim 对中文地名（尤其是古地名、历史地名）的解析准确率约 70-80%
4. **单线程运行**：为遵守礼貌性访问原则，采用单线程同步爬取，完整运行约需 30-60 分钟
